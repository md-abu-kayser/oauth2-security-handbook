# 00 — Prerequisites

These chapters establish the foundations required before studying OAuth 2.0 flows, tokens, OIDC, and security controls.

| Chapter | Focus |
|---|---|
| [01 — HTTP & REST Basics](./01-http-and-rest-basics.md) | HTTP semantics, REST, headers, redirects, APIs |
| [02 — Authentication vs Authorization](./02-authentication-vs-authorization.md) | Identity, sessions, permissions, scopes, roles |
| [03 — JWT Overview](./03-json-web-tokens-jwt-overview.md) | JWT structure, claims, signatures, validation |
| [04 — Cryptography Basics](./04-cryptography-basics.md) | Hashing, encryption, signatures, TLS, PKCE |
| [05 — OAuth vs SAML vs OIDC](./05-oauth-vs-saml-vs-oidc.md) | Protocol comparison and architecture selection |
