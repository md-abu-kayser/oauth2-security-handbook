# 12 — Code Snippets & Reference Implementations

Small, auditable examples for learning OAuth 2.0 and OIDC.

> These are educational reference implementations, not production identity infrastructure.

## Included

- Node.js / Express OAuth API scaffold
- Python / Flask Authorization Code + PKCE client
- Java / Spring Security Resource Server
- Postman collection
- Keycloak Docker Compose lab

## Production rule

Use a maintained, standards-compliant OAuth/OIDC implementation for production Authorization Server functionality.

Review issuer, audience, redirect URI, PKCE, state, nonce, token storage, secrets, key rotation, revocation, rate limiting, and monitoring before production.
