## Quality filter

Check:

```text
publication date
provider version
Authorization Code usage
PKCE usage
redirect URI validation
issuer/audience validation
secret handling
```

Avoid tutorials that teach legacy flows as the modern default or decode JWTs without cryptographic validation.
