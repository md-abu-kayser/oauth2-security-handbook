# Blogs, Newsletters & Communities

Prefer high-authority technical sources:

```text
IETF RFCs
OpenID Foundation
OAuth Working Group materials
official provider documentation
identity/security engineering blogs
```

Community discussions are useful for discovering real integration problems, but verify security claims against the standards and provider documentation.

## Research workflow

```text
community report
    ->
reproduce / isolate
    ->
provider docs
    ->
RFC / OIDC spec
    ->
handbook conclusion
```
